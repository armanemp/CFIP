# CFIP Applications

## Purpose
Deployable application entrypoints and workload composition roots for CFIP.

## Gate 0 status
Architecture-only materialization. Runtime implementation remains locked until Gate 0 closes.

## Boundary
Applications compose contexts, packages and adapters; they do not own domain semantics.

## Source mapping
CForex application/worker composition is evidence; target workload separation is an intentional scalability boundary.

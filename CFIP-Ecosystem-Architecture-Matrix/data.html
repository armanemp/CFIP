Data Platform

  • PostgreSQL: system of record
  • ClickHouse: analytical/time-series
  • Redis: cache و ephemeral state
  • Object Storage: datasets و immutable artifacts
  • DuckDB: local/research analytics
  • Arrow/Parquet: columnar interchange

Vespa، graph DB و lakehouse فقط در صورت اثبات نیاز workload و benchmark وارد می‌شوند.

Data correctness

Provider → Raw → Normalize → Validate → Deduplicate → Event-Time → Quality → Canonical → Outbox → Event Bus. PIT، lineage، revision و reproducibility الزامی هستند.

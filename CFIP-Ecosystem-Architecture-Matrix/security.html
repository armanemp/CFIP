Security / Identity / Governance

Identity

OAuth/OIDC، Keycloak، ZITADEL و Authentik در candidate set هستند.

Authorization

OpenFGA، OPA، Casbin و Zanzibar-style authorization برای fine-grained permissions بررسی می‌شوند.

Secrets / Supply Chain

Vault، Infisical، SOPS، age، Trivy، Semgrep، Bandit، CodeQL، Gitleaks، Syft و Grype candidateهای audit هستند.

Least privilege، tenant isolation، SSRF/tool restrictions، auditability، SBOM و agent sandboxing اجباری است.

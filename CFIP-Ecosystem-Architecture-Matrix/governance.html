Governance و Decision Freeze

Governance

تغییر runtime، contract، data ownership، license، security boundary یا topology نیازمند ADR است.

Autonomy

Observe → Propose → Checkpoint → Isolate → Risk Check → Sandbox → Independent Verification → Gates → Approval if required → Promote → Health Guard → Rollback

Freeze

پس از تکمیل catalog، بررسی alternatives، benchmark evidence، contract و gates، تصمیم freeze می‌شود و تغییرات بعدی فقط با ADR و impact analysis مجاز است.

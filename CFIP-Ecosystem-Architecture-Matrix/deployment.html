Deployment Profiles

  1. Development محدود: API، worker، web و زیرساخت حداقلی.
  2. Single-node production: process isolation، persistence، backup، monitoring و health gates.
  3. Scaled production: horizontal workers/API، partitioning، ClickHouse scaling، stream partitioning و object storage.
  4. Global: region-aware routing، data residency، regional workers و disaster recovery در صورت نیاز واقعی.

Microservice extraction فقط با evidence مربوط به scale، fault isolation، team ownership یا security انجام می‌شود.
